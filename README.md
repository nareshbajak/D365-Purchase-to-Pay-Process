# Purchase-to-Pay (P2P) Business Process

## About this Project

This project is based on the Purchase-to-Pay (P2P) process used in Microsoft Dynamics 365 Finance & Operations.

I created this project to understand how the purchasing process works in an ERP system. It explains each step from the business requirement to the final payment made to the vendor.

Although this is not a live D365 F&O implementation, it helped me learn the complete procurement workflow and understand how different departments work together during the purchasing process.

## Process Steps

- Business Requirement
- Purchase Requisition
- Manager Approval
- Purchase Order
- Vendor Delivers Goods
- Goods Receipt
- Vendor Invoice
- Payment
